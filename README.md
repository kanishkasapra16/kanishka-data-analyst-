# Kanishka Sapra Portfolio

Static GitHub Pages portfolio for Kanishka Sapra.

## Publish
1. Create a public repo named `kanishka-portfolio` under `kanishkasapra16`.
2. Upload all files in this folder.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. The site will appear at `https://kanishkasapra16.github.io/kanishka-portfolio/`.

Project preview images for public GitHub repositories are referenced directly from their GitHub raw files. Certificates, profile photo and resume are bundled locally.
